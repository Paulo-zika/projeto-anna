# ANNA - Jogos Educativos de Saúde

Aplicação web profissional com três jogos educativos sobre saúde:

1. **Quiz de Amamentação** - Quiz interativo automático com 8 perguntas, timer visual e sistema de pontuação
2. **Saúde Digestiva** - Aplicativo sobre câncer colorretal, obesidade e alimentação saudável
3. **Saúde Feminina** - Aplicativo sobre cuidados e bem-estar feminino

## 🚀 Como executar

1. Instale as dependências:
```bash
npm install
```

2. Execute o servidor de desenvolvimento:
```bash
npm run dev
```

3. Abra o navegador em `http://localhost:5173`

## 📦 Tecnologias

- React 18
- TypeScript
- Vite
- Tailwind CSS

## 🎮 Funcionalidades

### Quiz de Amamentação
- 8 perguntas educativas sobre amamentação
- Timer visual com contagem regressiva
- Sistema de pontuação em tempo real
- Feedback imediato com animações
- Sistema de estrelas (1-5 estrelas)
- Mensagens personalizadas baseadas no desempenho
- Confete animado ao acertar
- Transições suaves e profissionais

### Saúde Digestiva
- Informações sobre câncer colorretal
- Conteúdo sobre obesidade
- Dicas de alimentação saudável
- Quiz educativo

### Saúde Feminina
- Alimentação e saúde feminina
- Informações sobre ciclo menstrual
- Corpo e emoções
- Dicas rápidas de cuidado
